# Мини-проект: Library

## О нём
Этот мини-проект является моим первым "завершённым" проектом.  
В нём рассмотрены и были опробованы:  
- Работа с несколькими файлами и использование ввода с клавиатуры
- Создание классов и взаимосвязь между ними
- Обработка ошибок
- Сохранение и загрузка
- JUnit-тесты

## JUnit-тесты
Количество: 15
- Проверка разных ошибок
- Проверка сохранения и загрузки из файла
- Проверка логики программы

## Как запустить
``` bash
mvn compile exec:java
```

## Как запустить тесты
``` bash
mvn test
```

## Требования
- JDK 21+
- Maven

## Структура
- Book — книга (название, автор, статус выдачи)
- Library — каталог: добавить/найти/выдать/вернуть, сохранение в файл
- Main — меню в консоли
- BookTest, LibraryTest — тесты (15 шт.)
